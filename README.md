## 🎓 Research & Thesis

**A Data-Driven Framework for Career Recommendation and Competency Mapping to Bridge the Industry-Academia Gap**
*B.Sc. thesis, 2025–2026, supervised by Shammi Akhtar, Assistant Professor, CSE, UAP*

- ML pipeline with **Random Forest, XGBoost and LightGBM** to predict career paths and identify skill gaps
- Trained on a BdJobs dataset (~2,272 rows) and a student dataset (~3,399 rows)
- **Competency mapping** with cosine similarity
- **Django** backend with an interactive dashboard and a competency radar across technical and soft-skill domains

**RM22: Scalable IoT-Based Research and Educational Robot Platform** (2025–2026, team of four)
ESP8266-based smart car with wireless control, sensor integration and real-time data monitoring.
